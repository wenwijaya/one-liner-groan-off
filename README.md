A single original dad joke, one line, for [The One-Liner Groan-Off](https://make.fun/bounty/u-alfasurya91-the-one-liner-groan-off-5a1febd5) on make.fun. The program writes the joke to `/output/entry.txt` — nothing else is needed: no code, no data, just the line.

> I told my wife I wanted to be a baker, but I couldn't make enough dough, so now I just loaf around the house.

## Run it

```sh
node main.ts
```

This writes the one-line joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set) and exits 0.
